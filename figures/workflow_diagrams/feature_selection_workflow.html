01.8 — Feature Selection · rdmoldes descriptor set

Which 50 descriptors actually earn their place?

A six-stage funnel that starts at 316 raw rdkit-descriptor features and asks, at every step, "does removing this cost any predictive signal?" — ending in a 2-descriptor set that keeps 82% of the ceiling.

Dataset: 3,509 unique ADME molecules Endpoints: HLM, RLM, MDR1, SOL Featureset: rdmoldes only — FCFP4/ECFP4 untouched Granularity: decisions made per named descriptor, never per raw feature

Stage by stage

Method, mechanism, and the reasoning behind each cut.

0

Descriptor map + constant filter variance threshold

The paper's 50 named rdmoldes descriptors expand to 316 numeric features (44 are single scalars; 6 are vector-valued, e.g. AUTOCORR2D → 192 columns). Any descriptor whose features have ~zero variance across all 3,509 molecules — it returns essentially the same value for every compound — is dropped outright. CalcPBF and CalcSpherocityIndex drop here: both formulas evaluate to exactly 0 when every atom has z=0, which is true for this whole dataset (flat 2D depiction coordinates inherited from the source SDFs, not real conformers — see ADR-011).

a descriptor that can't distinguish any two molecules can't help any model, by construction — free to remove before any correlation/model logic runs.

50 → 48descriptors
316 → 314features
1

Components + mutual information PCA · MI

Every surviving descriptor is reduced to its top principal components — scalar descriptors reduce to 1, multi-feature blocks (like AUTOCORR2D) to several — so a 192-column block isn't judged on one coincidentally-informative axis. Mutual information against each endpoint's target is then computed per component, taking the max over (component, endpoint) per descriptor.

this isn't a filtering step by itself — it builds the MI score used as a tiebreaker in stages 2 and 3, and the rule "useful for any endpoint" deliberately avoids penalizing a descriptor that only matters for one of the four.

2

Correlation prune canonical correlation (CCA)

For every near-duplicate pair of descriptors — canonical correlation between their top-component sets > 0.9 — drop the one with lower max-MI. CCA generalizes Pearson correlation from a single variable to a whole set of components on each side, so a multi-feature descriptor isn't judged only on its first PC.

two descriptors that move together linearly are redundant no matter how each is internally structured; CCA is the correct measure for that redundancy at the group level rather than the single-axis level.

0.406mean CV R²
48 → 27descriptors
314 → 92features
97%of ceiling
known limitation CCA only catches linear redundancy — a genuinely nonlinear dependency between two descriptors could survive this step. Not fixed here because VIF and the RFE/R² audit downstream both re-check against real model performance, so a wrong call isn't silently trusted.
3

VIF prune variance inflation factor

Iteratively drop the single highest-VIF descriptor block — multicollinearity measured against all other surviving blocks at once, not just pairwise — until every survivor is at or below threshold 5.0. Near-ties broken by MI.

CCA (stage 2) only checks pairs; a descriptor can look fine against every individual peer while still being a near-linear combination of three others jointly. VIF catches that group-level redundancy.

0.382mean CV R²
27 → 16descriptors
92 → 40features
91%of ceiling
4

LightGBM recursive elimination RFE · gain-importance

Runs on each endpoint's own real feature columns (not PC1). At every step: fit LightGBM per endpoint, score each remaining descriptor by max gain-importance across endpoints, drop the lowest scorer, log the CV R². Run all the way to 1 descriptor so the full trace — not just an arbitrary stopping floor — is visible; the first real elbow sits at 5→4 descriptors.

a visible trace lets a bad elimination show up as a drop rather than being silently accepted — earlier runs stopped at 10 or 3 descriptors with no such justification and would have missed the second, much larger cliff later in the trace (3→2, the single biggest drop anywhere).

0.356mean CV R²
16 → 5descriptors
40 → 29features
85%of ceiling
bug found & fixed RFE was eliminating on scikit-learn's default feature_importances_ — split-count, not gain — despite every surrounding comment describing gain. Caught because CalcEccentricity (flat-2D-geometry descriptor, ADR-011) survived to the final 5 with zero gain-importance, while its rank-twin CalcNPR2 (Spearman ρ=1.0) had already been dropped at correlation-prune. Fixed by setting importance_type='gain' explicitly; the corrected final 5 replaced CalcEccentricity/CalcPMI3 with CalcNumAromaticCarbocycles/CalcChi3v.
5

Standalone-ranked refinement solo CV R² ranking

A distinct question from RFE: not "what's safe to remove one at a time," but "which individual descriptors carry the most signal on their own?" Each of the pool's descriptors is scored by its standalone CV R² (a single-descriptor model), then the top-N by that ranking is compared directly against RFE's own trace at the same N.

RFE's greedy, marginal scoring has a blind spot at the tail: once a few descriptors are individually strong and partially correlated with each other, gain-importance undersells whichever one entered the model second. Standalone-ranked sidesteps that entirely by scoring each descriptor in isolation.

0.355Top-3 solo R²
0.346Top-2 solo R²
82–85%of ceiling
what the comparison found Standalone, PEOE_VSA (R²=0.265) and SlogP_VSA (R²=0.255) are the two strongest descriptors in the entire 16-descriptor pool — yet RFE's greedy trace drops them first (5→4 and 3→2, including the trace's single biggest drop) because gain-importance is a marginal measure: once one VSA descriptor is in the model, the other's added value looks small even though its standalone value is huge. At N=2, RFE's own picks (CalcTPSA + CalcChi3v) score R²=0.066 — barely above noise — versus 0.346 for the standalone-ranked pair.

Recommendation

N = 2 — PEOE_VSA + SlogP_VSA

Not a compromise pick: it's the actual point of diminishing returns. 26 of the 5-descriptor RFE set's 29 features, 96% of what the full 16→5 RFE pipeline achieves (0.346 vs. 0.356 R²), and standalone-ranked rather than greedily eliminated — so it doesn't inherit RFE's tail-end unreliability. Every descriptor added past these two buys single-digit R² returns at best.

PEOE_VSA

Van der Waals surface area binned by Gasteiger partial charge (14 bins) — how much of the molecule's surface is electron-rich vs. electron-poor. Its polarity / H-bonding character.

SlogP_VSA

Same surface-area partitioning, binned by each atom's Crippen logP contribution (12 bins) — how much surface is lipophilic vs. not, and where.

Together: a compact "polar surface vs. lipophilic surface" fingerprint — directly mechanistic for all 4 endpoints modelled here (HLM/RLM clearance, MDR1 efflux, aqueous solubility are all lipophilicity/polarity-governed ADME properties).
